# WebGL 그래픽스 Lec11 - TPS 우주선 시점 구현

기존 강의 코드는 트랙볼 카메라가 원점 [0, 0, 0]에 고정되어 있었다.  
동적 위치 좌표 하나를 지정해 트랙볼 카메라의 중심과 로켓의 좌표를 일치시키면 TPS(3인칭) 시점을 만들 수 있을 것이라 생각하여 해당 코드를 작성하였다.

## 수정 포인트

1. **동적 기준점('shipPos') 동기화**
   * 월드 공간에 동적 좌표 'shipPos'를 생성하고, 트랙볼 카메라의 공전 중심과 로켓의 위치를 'shipPos' 로 일치시켰다.

2. **오버더숄더 카메라 오프셋 분리 (BACK / UP)**
   * 트랙볼 카메라 위치값을 두 개로 나누어 트랙볼의 중심('shipPos') 기준 뒤로 얼마나 갔는지('Back')와 위로 얼마나 갔는지('Up')로 분리했다.
   * 이를 통해 로켓의 뒷면(엉덩이)만 보이는 것이 아니라 로켓의 윗면 실루엣이 보이도록 시야 구도를 잡았다.

3. **단일 VAO 통합 메시 구성**
   * 로켓의 원뿔과 원통 두 개의 도형을 하나의 VAO 메시로 합쳐, 화면에 그려낼 때 드로우 콜을 한 번만 호출하도록 만들었다.

## 생각 포인트

* 로켓이 카메라 시선과 동기화되어 항상 같은 뒷모습을 보이도록 만들었는데, 이럴 거면 매 프레임 3D 메시를 연산하는것보단 화면에 2D 텍스처(스프라이트)를 하나 붙여 같은 모습을 보여주는 편이 렌더링 효율 면에서 더 낫다고 생각한다.
* 또한 2D 픽셀 아트로 기체를 표현하면 고전 아케이드 슈팅 게임 같은 레트로한 느낌의 게임성이 살아날꺼 같다.
* 하지만 3D 게임에서 기채가 먼저 움직이고 이후에 카메라가 따라가는 카메라 지연 효과를 넣을때는 3D메시가 더 효과적일것 같다
